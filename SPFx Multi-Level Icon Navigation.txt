# SPFx Multi-Level Icon Navigation Web Part — Complete Guide

## Architecture Overview

```
SharePoint List (NavigationConfig)
        │
        ▼
SPFx Web Part (reads list via REST API)
        │
        ▼
Renders Icon Grid with Expandable Menus
   ├── Level 1: Top Icons (no URL — click expands sub-items)
   │     ├── Level 2: Sub-items (some have URLs, some expand further)
   │     │     ├── Level 3: Sub-sub-items (all have URLs)
```

---

## STEP 1: Create the SharePoint List

### List Name: `NavigationConfig`

Go to **Site Contents → New → List** and create columns:

| Column Name   | Type                          | Required | Description                                    |
|---------------|-------------------------------|----------|------------------------------------------------|
| Title         | Single line of text (default) | Yes      | Display name of the menu item                  |
| IconUrl       | Single line of text           | No       | URL to icon image (only for top-level items)   |
| ParentItem    | Lookup (this list → Title)    | No       | Empty = top-level; otherwise points to parent  |
| LinkUrl       | Single line of text           | No       | Empty = expands children; filled = navigates   |
| SortOrder     | Number                        | Yes      | Controls display order within same level       |
| IsActive      | Yes/No                        | Yes      | Toggle items on/off without deleting           |
| OpenInNewTab  | Yes/No                        | No       | Whether link opens in new browser tab          |
| Description   | Single line of text           | No       | Tooltip text shown on hover                    |

```typescript
export interface INavigationItem {
  Id: number;

  IconUrl: string;
  ParentItemId: number | null;
  LinkUrl: string;
  SortOrder: number;
  IsActive: boolean;
  OpenInNewTab: boolean;
  Description: string;
  // Computed at runtime
  children?: INavigationItem[];
  isExpanded?: boolean;
  level?: number;
```

### 6B. Data Service — `src/webparts/iconNavigation/services/NavigationService.ts`

```typescript
import { SPHttpClient, SPHttpClientResponse } from '@microsoft/sp-http';
import { INavigationItem } from '../models/INavigationItem';

export class NavigationService {
  private spHttpClient: SPHttpClient;
  private siteUrl: string;
  private listName: string;

  constructor(spHttpClient: SPHttpClient, siteUrl: string, listName: string) {
    this.spHttpClient = spHttpClient;
    this.siteUrl = siteUrl;
    this.listName = listName;
  }

  /**
   * Fetch all active nav items from the SharePoint list
   */
  public async getNavigationItems(): Promise<INavigationItem[]> {
    const apiUrl = `${this.siteUrl}/_api/web/lists/getbytitle('${this.listName}')/items`
      + `?$select=Id,Title,IconUrl,ParentItem/Id,ParentItem/Title,LinkUrl,SortOrder,IsActive,OpenInNewTab,Description`
      + `&$expand=ParentItem`
      + `&$filter=IsActive eq 1`
      + `&$orderby=SortOrder asc`
      + `&$top=500`;

    const response: SPHttpClientResponse = await this.spHttpClient.get(
      apiUrl,
      SPHttpClient.configurations.v1
    );

    if (!response.ok) {
      throw new Error(`Failed to fetch navigation items: ${response.statusText}`);
    }

    const data = await response.json();

    return data.value.map((item: any) => ({
      Id: item.Id,
      Title: item.Title,
      IconUrl: item.IconUrl || '',
      ParentItemId: item.ParentItem ? item.ParentItem.Id : null,
      LinkUrl: item.LinkUrl || '',
      SortOrder: item.SortOrder || 0,
      IsActive: item.IsActive,
      OpenInNewTab: item.OpenInNewTab || false,
      Description: item.Description || '',
      children: [],
      isExpanded: false,
      level: 0
    }));
  }

  /**
   * Build a tree structure from the flat list
   */
  public buildTree(items: INavigationItem[]): INavigationItem[] {
    const itemMap: Map<number, INavigationItem> = new Map();
    const roots: INavigationItem[] = [];

    // Index all items by Id
    items.forEach(item => {
      item.children = [];
      item.isExpanded = false;
      itemMap.set(item.Id, item);
    });

    // Build parent-child relationships
    items.forEach(item => {
      if (item.ParentItemId && itemMap.has(item.ParentItemId)) {
        const parent = itemMap.get(item.ParentItemId)!;
        item.level = (parent.level || 0) + 1;
        parent.children!.push(item);
      } else {
        item.level = 0;
        roots.push(item);
      }
    });

    // Sort children at each level
    const sortChildren = (nodes: INavigationItem[]) => {
      nodes.sort((a, b) => a.SortOrder - b.SortOrder);
      nodes.forEach(node => {
        if (node.children && node.children.length > 0) {
          sortChildren(node.children);
        }
      });
    };
    sortChildren(roots);

    return roots;
  }
}
```

### 6C. Renderer — `src/webparts/iconNavigation/components/NavigationRenderer.ts`

```typescript
import { INavigationItem } from '../models/INavigationItem';
import styles from '../IconNavigationWebPart.module.scss';

export class NavigationRenderer {
  private container: HTMLElement;
  private navigationTree: INavigationItem[];

  constructor(container: HTMLElement) {
    this.container = container;
    this.navigationTree = [];
  }

  /**
   * Main render method
   */
  public render(tree: INavigationItem[]): void {
    this.navigationTree = tree;
    this.container.innerHTML = '';

    // ── Section 1: Top-level icon grid ──
    const gridContainer = document.createElement('div');
    gridContainer.className = styles.iconGrid;

    tree.forEach(item => {
      const iconTile = this.createIconTile(item);
      gridContainer.appendChild(iconTile);
    });

    this.container.appendChild(gridContainer);

    // ── Section 2: Expandable sub-menu area ──
    const submenuArea = document.createElement('div');
    submenuArea.className = styles.submenuArea;
    submenuArea.id = 'submenu-area';
    this.container.appendChild(submenuArea);
  }

  /**
   * Create a clickable icon tile for top-level items
   */
  private createIconTile(item: INavigationItem): HTMLElement {
    const tile = document.createElement('div');
    tile.className = styles.iconTile;
    tile.setAttribute('data-item-id', item.Id.toString());
    tile.title = item.Description || item.Title;

    // Icon image
    if (item.IconUrl) {
      const img = document.createElement('img');
      img.src = item.IconUrl;
      img.alt = item.Title;
      img.className = styles.iconImage;
      tile.appendChild(img);
    } else {
      // Fallback: first letter
      const placeholder = document.createElement('div');
      placeholder.className = styles.iconPlaceholder;
      placeholder.textContent = item.Title.charAt(0).toUpperCase();
      tile.appendChild(placeholder);
    }

    // Label
    const label = document.createElement('span');
    label.className = styles.iconLabel;
    label.textContent = item.Title;
    tile.appendChild(label);

    // Click handler
    tile.addEventListener('click', () => this.handleTopLevelClick(item, tile));

    return tile;
  }

  /**
   * Handle click on a top-level icon
   */
  private handleTopLevelClick(item: INavigationItem, tileElement: HTMLElement): void {
    const submenuArea = document.getElementById('submenu-area')!;

    // Toggle: if already expanded, collapse
    if (item.isExpanded) {
      item.isExpanded = false;
      tileElement.classList.remove(styles.activeTile);
      submenuArea.innerHTML = '';
      submenuArea.classList.remove(styles.submenuVisible);
      return;
    }

    // Collapse any other expanded top-level item
    this.navigationTree.forEach(navItem => {
      navItem.isExpanded = false;
    });
    document.querySelectorAll(`.${styles.activeTile}`).forEach(el => {
      el.classList.remove(styles.activeTile);
    });

    // Expand this item
    item.isExpanded = true;
    tileElement.classList.add(styles.activeTile);

    // Render sub-items
    submenuArea.innerHTML = '';
    if (item.children && item.children.length > 0) {
      // Arrow pointer to show which icon is expanded
      const arrow = document.createElement('div');
      arrow.className = styles.submenuArrow;
      // Position arrow under the clicked tile
      const tileRect = tileElement.getBoundingClientRect();
      const containerRect = this.container.getBoundingClientRect();
      arrow.style.left = `${tileRect.left - containerRect.left + tileRect.width / 2 - 10}px`;
      submenuArea.appendChild(arrow);

      // Header
      const header = document.createElement('div');
      header.className = styles.submenuHeader;
      header.textContent = item.Title;
      submenuArea.appendChild(header);

      // Sub-items list
      const subList = this.createSubmenuList(item.children, 1);
      submenuArea.appendChild(subList);
      submenuArea.classList.add(styles.submenuVisible);
    }
  }

  /**
   * Recursively create sub-menu list
   */
  private createSubmenuList(items: INavigationItem[], level: number): HTMLElement {
    const list = document.createElement('ul');
    list.className = `${styles.submenuList} ${styles[`level${level}`] || ''}`;

    items.forEach(item => {
      const li = document.createElement('li');
      li.className = styles.submenuItem;

      const hasChildren = item.children && item.children.length > 0;
      const hasLink = item.LinkUrl && item.LinkUrl.trim() !== '';

      // Create the clickable row
      const row = document.createElement('div');
      row.className = styles.submenuRow;

      if (hasLink && !hasChildren) {
        // ── This item has a URL → render as a link ──
        const link = document.createElement('a');
        link.href = item.LinkUrl;
        link.textContent = item.Title;
        link.className = styles.submenuLink;
        if (item.OpenInNewTab) {
          link.target = '_blank';
          link.rel = 'noopener noreferrer';
        }
        row.appendChild(link);
      } else if (hasChildren) {
        // ── This item has children → render as expandable ──
        const toggle = document.createElement('span');
        toggle.className = styles.submenuToggle;
        toggle.textContent = item.Title;
        row.appendChild(toggle);

        // Expand/collapse chevron
        const chevron = document.createElement('span');
        chevron.className = styles.chevron;
        chevron.innerHTML = '&#9654;'; // ▶ right arrow
        row.appendChild(chevron);

        // Child container (hidden initially)
        const childContainer = document.createElement('div');
        childContainer.className = styles.childContainer;
        childContainer.style.display = 'none';

        const childList = this.createSubmenuList(item.children!, level + 1);
        childContainer.appendChild(childList);

        // Click handler for expand/collapse
        row.addEventListener('click', (e) => {
          e.stopPropagation();
          const isVisible = childContainer.style.display !== 'none';
          childContainer.style.display = isVisible ? 'none' : 'block';
          chevron.classList.toggle(styles.chevronExpanded);
          row.classList.toggle(styles.submenuRowExpanded);
        });

        li.appendChild(row);
        li.appendChild(childContainer);
        list.appendChild(li);
        return; // skip the default append below
      } else {
        // No URL, no children — just a label
        const span = document.createElement('span');
        span.textContent = item.Title;
        span.className = styles.submenuLabel;
        row.appendChild(span);
      }

      li.appendChild(row);
      list.appendChild(li);
    });

    return list;
  }

  /**
   * Show loading state
   */
  public renderLoading(): void {
    this.container.innerHTML = `
      <div class="${styles.loading}">
        <div class="${styles.spinner}"></div>
        <span>Loading navigation...</span>
      </div>
    `;
  }

  /**
   * Show error state
   */
  public renderError(message: string): void {
    this.container.innerHTML = `
      <div class="${styles.error}">
        <span class="${styles.errorIcon}">⚠</span>
        <span>${message}</span>
        <button class="${styles.retryButton}" id="retry-btn">Retry</button>
      </div>
    `;
  }
}
```

### 6E. Main Web Part — `src/webparts/iconNavigation/IconNavigationWebPart.ts`

```typescript
import { Version } from '@microsoft/sp-core-library';
import {
  BaseClientSideWebPart,
  IPropertyPaneConfiguration,
  PropertyPaneTextField
} from '@microsoft/sp-webpart-base';
import { SPHttpClient } from '@microsoft/sp-http';

import styles from './IconNavigationWebPart.module.scss';
import { NavigationService } from './services/NavigationService';
import { NavigationRenderer } from './components/NavigationRenderer';

export interface IIconNavigationWebPartProps {
  listName: string;
  sectionTitle: string;
  sectionSubtitle: string;
}

export default class IconNavigationWebPart extends BaseClientSideWebPart<IIconNavigationWebPartProps> {
  private renderer: NavigationRenderer;
  private navService: NavigationService;

  public render(): void {
    // Set up container
    this.domElement.innerHTML = `
      <div class="${styles.iconNavigation}">
        <div class="${styles.sectionTitle}">${this.properties.sectionTitle || ''}</div>
        <div class="${styles.sectionSubtitle}">${this.properties.sectionSubtitle || ''}</div>
        <div id="nav-container"></div>
      </div>
    `;

    const container = this.domElement.querySelector('#nav-container') as HTMLElement;
    this.renderer = new NavigationRenderer(container);
    this.navService = new NavigationService(
      this.context.spHttpClient,
      this.context.pageContext.web.absoluteUrl,
      this.properties.listName || 'NavigationConfig'
    );

    this.loadNavigation();
  }

  private async loadNavigation(): Promise<void> {
    this.renderer.renderLoading();

    try {
      const items = await this.navService.getNavigationItems();
      const tree = this.navService.buildTree(items);
      this.renderer.render(tree);
    } catch (error) {
      console.error('Navigation load error:', error);
      this.renderer.renderError('Failed to load navigation. Check list permissions.');

      // Retry button
      const retryBtn = this.domElement.querySelector('#retry-btn');
      if (retryBtn) {
        retryBtn.addEventListener('click', () => this.loadNavigation());
      }
    }
  }

  protected get dataVersion(): Version {
    return Version.parse('1.0');
  }

  protected getPropertyPaneConfiguration(): IPropertyPaneConfiguration {
    return {
      pages: [
        {
          header: { description: 'Configure the Icon Navigation web part' },
          groups: [
            {
              groupName: 'Data Source',
              groupFields: [
                PropertyPaneTextField('listName', {
                  label: 'SharePoint List Name',
                  description: 'Name of the list containing navigation items',
                  value: 'NavigationConfig'
                })
              ]
            },
            {
              groupName: 'Display',
              groupFields: [
                PropertyPaneTextField('sectionTitle', {
                  label: 'Section Title',
                  value: "You haven't taught until they have learned"
                }),
                PropertyPaneTextField('sectionSubtitle', {
                  label: 'Section Subtitle',
                  value: "All of the material needed to teach Crane NXT's world class business system can be found here."
                })
              ]
            }
          ]
        }
      ]
    };
  }
}
```

### Deploy to SharePoint On-Prem App Catalog

1. Go to **Central Administration → Apps → Manage App Catalog**
2. Upload the `.sppkg` file
3. Trust the solution when prompted
4. Go to your target site → **Site Contents → Add an App → IconNavigation**
5. Edit any page → Add the **IconNavigation** web part
6. In the web part property pane, set the list name to `NavigationConfig`

## STEP 8: Managing Navigation (No Code Changes Needed)

### Adding a new top-level icon:
1. Go to the `NavigationConfig` list
2. Add a new item: Title = "New Section", IconUrl = "/path/to/icon.png", ParentItem = blank, SortOrder = next number

### Adding a sub-item under an existing icon:
1. Add a new item: Title = "Sub Page", ParentItem = select parent, LinkUrl = "/sites/.../page.aspx", SortOrder = 1

### Adding a sub-sub-item:
1. Add a new item: Title = "Sub Sub Page", ParentItem = select the sub-item (not the top icon), LinkUrl = "/sites/.../page.aspx", SortOrder = 1

### Hiding an item temporarily:
1. Edit the item → set IsActive = No

### Reordering:
1. Change SortOrder numbers. Items with lower numbers appear first.

---

## STEP 9: Icon Management

Upload your icons to a document library (e.g., `/sites/CBS/SiteAssets/NavIcons/`) and reference them in the IconUrl column. Recommended format: PNG with transparent background, 128×128 px.

## Summary of What Admins Can Control via the List

| Action                        | How                                           |
|-------------------------------|-----------------------------------------------|
| Add/remove top-level icons    | Add/delete rows with no ParentItem            |
| Add/remove sub-items          | Add/delete rows with ParentItem set            |
| Add sub-sub-items             | Set ParentItem to a sub-item (not top-level)  |
| Change icon image             | Update IconUrl column                         |
| Change link destination       | Update LinkUrl column                         |
| Reorder items                 | Change SortOrder numbers                      |
| Hide/show items               | Toggle IsActive                               |
| Change label text             | Edit Title column                             |
| Open link in new tab          | Set OpenInNewTab = Yes                        |
| Add tooltip                   | Fill in Description column                    |
